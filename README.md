## 🎯 Sobre o projeto

Este repositório documenta minha evolução através do **[OverTheWire Bandit](https://overthewire.org/wargames/bandit/)**, uma série de desafios criada para ensinar fundamentos de segurança e administração de sistemas Linux de forma prática.

A ideia não é apenas completar os níveis, mas **entender os conceitos por trás de cada desafio e registrar os principais aprendizados**.

> 🚀 **Objetivo:** completar os 34 níveis, do `Bandit 0` ao `Bandit 33`, e utilizar essa base como preparação para CTFs reais.

> **Não quero apenas resolver o desafio. Quero entender por que a solução funciona.**

Estou utilizando essa jornada para desenvolver uma mentalidade mais voltada à resolução de problemas:

```text
Problema
   ↓
Investigação
   ↓
Hipótese
   ↓
Teste
   ↓

   ↓
```

O objetivo é transformar cada desafio em conhecimento que possa ser aplicado posteriormente em ambientes reais de infraestrutura e segurança.
